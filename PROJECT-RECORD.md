# Rulers Language project record

## Purpose

A browser-based teaching guide for helping people give AI clearer instructions through three separate work modes—Design, Implementation, and Verification—and improve them from observed outcomes. The opening is written as a personal lesson from Vaishnav to the reader.

The name refers to expressive, deliberate language, not status or power over an AI system. Clear instructions can improve direction, but do not unlock intelligence, guarantee correctness, or make the system reward authority.

## Site contents

- Guided prompt builder with separate Design, Implementation, and Verification modes.
- Atmospheric dark visual theme with the supplied image layered behind the personal before-and-after teaching example in the opening view.
- Supplied 3840×1374 panoramic fantasy image used as an optional system-learning interlude before the project lessons.
- Illustrated All-Weapon Synchronization card presents the multi-armed entity and the system directive: "You will be using each weapon. One for all work power, once you understand what Rulers Language is."
- Longer project paths, tool directory, lessons, workflow, glossary, checklist, and FAQ grouped into optional disclosures.
- Eight tone choices, each with its best use and a practical risk to watch.
- Editable prompts with copy and browser share-sheet support where available.
- Four coding-agent lessons with copy-ready prompts, example loading, instruction rationale, evidence criteria, common failures, and practical exercises.
- Browser-local lesson log, capped at the 20 most recent entries and retaining the prompt, outcome, concrete observation, correction, and optional evidence note.
- Backward-compatible reading of earlier lesson records; older entries remain visible with unavailable prompt/evidence clearly identified.
- Learning paths and a finder for tools to build and publish software.
- Plain-language software glossary, practical workflow, FAQs, and launch checklist.
- Datum is used only as a hypothetical vehicle-platform teaching scenario; commercial research is exploratory and does not itself validate demand.

## Privacy and data

- The site does not connect to a model or transmit prompt-builder content to a server.
- The prompt and lesson log are stored only in the visitor's current browser when explicitly saved. They can be cleared from that browser.
- Visitors should not enter secrets, private records, or sensitive personal information.

## Update procedure

1. Edit the source files in this folder.
2. Review the changes and run the applicable checks.
3. Push changed files to the repository's `main` branch.
4. Wait for the GitHub Pages deployment.
5. Verify the public URL and test prompt generation, sharing/copying, local lesson storage, and the responsive layout.
