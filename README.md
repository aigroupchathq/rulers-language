# AI Group Chat

A practical guide to planning, building, testing and publishing software with AI tools.

## Project files

- `index.html` contains the page content and metadata.
- `styles.css` contains the responsive design and accessibility states.
- `script.js` contains the tool finder, brief builder, filters and checklist.
- `README.md` explains how to run and publish the project.
- `PROJECT-RECORD.md` keeps the repository and publishing details.

## Preview locally

Open `index.html` in a browser. This is a static site and does not require a package install or build command.

## Publish on GitHub Pages

1. Push the project files to the `main` branch of a public GitHub repository.
2. In the repository, open **Settings**, then **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)` folder, then save.
5. Wait for the Pages deployment. The expected project URL is recorded in `PROJECT-RECORD.md`.

## Update the site

Edit the source files, commit and push them to `main`. GitHub Pages publishes the updated static files after its deployment finishes.

## Notes

- Tool features and prices change. Check each provider's official site for current details.
- The launch checklist stores progress in the visitor's browser only.
- Do not put passwords, API keys or private data in public project files.
